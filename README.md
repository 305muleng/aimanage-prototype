# 爱管理｜Sprint 1 可运行原型

这是一个适合作业演示的项目协作系统原型，使用 Java 17、Spring Boot、Thymeleaf 和 Spring Data JPA 开发。当前默认使用 MySQL，原 H2 文件数据库保留作为迁移前备份。

前端采用克制的 Notion 风格：米色侧栏、白色文档区、轻边框、小圆角、线性图标和低干扰悬停反馈。桌面、平板和手机均可使用。

## 已实现的用户故事

UML 图删除：项目负责人可通过每张图卡片右上角的“删除”按钮，在确认后删除整张图及其节点、连线，关联用户故事和任务保留。删除后自动显示剩余第一张图，全部删除后显示空页面；成员只读。删除接口校验项目归属及 CSRF，并在同一事务中清理图内数据。

UML 简化操作：点击图类型可一键创建含两个示例元素及连线的基础框架，默认名称自动生成；空白自定义图仍可创建。画布工具支持快捷添加元素和两次点选连线，结构说明及关联设置默认折叠。节点可在当前图允许的类型内切换，保留ID及位置，跨图和非法类型仍禁止。现有视图数据不替换。当前自动化测试51项。

UML 视图第一版：侧栏 /uml，每个项目支持创建多张类图、用例图、时序图、活动图。负责人新增/编辑节点、增加或移除连线、拖动并保存位置、关联本项目故事和任务；项目成员只读查看，点击关联可跳转 Backlog、任务和甘特图。数据保存到 MySQL 的 uml_view / uml_node / uml_edge。类图采用文本结构说明，时序消息按创建顺序排列；尚不支持自动从源代码生成、完整 UML 关系类型、节点删除、消息重排序、双向变更提示和多人实时同步。当前测试共49项。

Sprint 管理入口 `/sprints` 新增真实任务甘特图：按项目及故事地图 Sprint 规划标签筛选；四周日期窗口、任务状态色条、真实完成率/逾期统计，负责人可保存计划开始和结束日期到 MySQL。旧任务没有开始日期时不生成虚假持续条。开发人员仅展示本人任务。此版不含真实 Sprint 创建维护、拖拽排期、实际开始结束时间及任务依赖线；统计按当前筛选范围计算。点击时间条可跳转任务工作台。自动化测试当前 46 项。

Product Backlog 新增真实用户故事地图：参考三个 Epic（用户管理与权限、任务与协作、数据与分析），按 Sprint 1–3 规划标签及待规划分层，功能分组可自定义。使用现有 STORY 数据，卡片可跳转详情；负责人通过“调整故事地图位置”保存 Epic、功能分组、阶段到 MySQL，成员只读。新故事默认 Epic 1 / 待规划，不自动插入模板示例。Sprint 标签尚不是真实迭代记录，不表示进度或完成状态。目前自动化测试 43 项。

新增 E2-01 / E2-02：侧栏 Product Backlog 打开 `/backlog`，选择项目后新增或编辑需求与用户故事；用户故事验收标准必填，支持四档优先级及所属需求关联，写入 MySQL 的 `backlog_item` 表。负责人只能编辑自己的项目，成员只读查看已加入项目。暂不提供删除功能。

新增 E2-04：负责人工作台每条任务的操作区可保存优先级和关联用户故事，也可解除关联。仅允许关联当前项目的用户故事。原有任务空优先级按 MEDIUM 处理，无故事关联保持兼容。需求和故事共用一张表，以 REQUIREMENT / STORY 类型区分。自动化测试目前共 42 项。

| --- | --- |
| E1-US01 用户注册 | 姓名、账号、密码及确认密码校验，禁止重复账号，默认注册为开发人员，密码以加盐 PBKDF2 保存 |
| E1-US03 个人信息查看 | 三种身份可在账户与资料页查看账号、角色、姓名、邮箱、联系电话和简介 |
| E1-US04 个人信息修改 | 修改本人的姓名、邮箱、联系电话和简介，校验输入并保存到 MySQL，同步侧栏姓名 |
| E1-US02 用户登录 | 账号密码登录，错误信息提示，按角色进入工作台 |
| E1-US11 角色创建 | 管理员创建自定义角色名称和说明，选择继承开发人员、项目负责人或管理员权限 |
| E1-US12 角色分配 | 管理员为用户分配角色，保存到 MySQL，已有登录会话下次请求按新权限生效 |
| E1-US13 角色权限 / E1-06 | 管理员、项目负责人、开发人员三角色统一后端访问控制；业务层校验身份、项目范围及本人任务；侧栏提供真实权限说明 |
| E1-US05 项目创建 | 填写名称和简介创建项目 |
| E1-US06 项目基本信息维护 | 负责人编辑自己项目的名称和简介，开发人员可查看参与项目的信息 |
| E1-US07 项目成员加入 | 从开发人员中添加成员，阻止重复添加 |
| E1-US08 项目成员移除 | 移除项目成员；名下有任务时需先转交任务，移除不删除系统账号 |
| E1-US09 成员状态与职责管理 | 设置正常或暂停参与，维护项目身份和职责说明；暂停成员不能接收新任务或更新状态 |
| E1-US10 项目身份与职责查看 | 开发人员在项目与成员页查看本人身份职责及团队分工，仅展示其加入的项目 |
| E2-US05 任务创建与编辑 | 创建任务并编辑标题、描述、截止日期、负责人 |
| E2-US06 任务负责人分配 | 只能把任务分配给当前项目成员 |
| E2-US08 任务状态更新 | 开发人员可将自己的任务更新为待处理、进行中、已完成 |
| E2-US09 我的任务 | 开发人员登录后只看到分配给自己的任务 |

## 完整产品界面

除以上已实现用户故事外，原型还为其他规划功能提供了界面预览、导航入口和操作按钮。它们按 8 个模块组织：

- 账户与个人资料；
- 项目与成员；
- 角色与权限；
- Product Backlog；
- Sprint 管理；
- 任务与协作；
- AI 协作；
- 数据与分析。

标记为“界面预览”的按钮不写入数据，点击时会提示“将在后续 Sprint 中实现”；标记为“已实现”的功能会进入当前可运行的 Sprint 1 工作流。这样既能完整展示产品规划，也不会让演示者误把占位交互当成已完成业务。

## 最快运行方式

环境要求：JDK 17 或更高版本、Maven 3.9 或兼容版本，以及已启动的 MySQL。

本机已创建 `aimanage` 数据库和专用账号 `aimanage_app`。连接配置保存在不纳入版本控制的 `.local/mysql.properties` 中。迁移前的 H2 压缩备份也保存在 `.local` 中，原 `data/aimanage.mv.db` 保留。

在项目根目录打开终端并执行：

```powershell
mvn "-Dmaven.repo.local=.m2-cache" -DskipTests package
powershell -ExecutionPolicy Bypass -File scripts/start-mysql.ps1
```

看到 `Started AiManageApplication` 后，浏览器访问：

<http://localhost:8080>

网页通过 Java 后端读写本机 MySQL 的 `aimanage` 数据库，重启不会丢失数据。启动脚本会加载本机连接配置，并设置兼容本机 Java 的短路径临时目录。若 PATH 中的 Maven 版本过旧，可使用 `.tools/apache-maven-3.9.9/bin/mvn.cmd` 编译。

如需单独运行迁移前的 H2 数据库，可明确指定 `--spring.profiles.active=h2`；它不会与 MySQL 自动同步。

登录页点击演示账号卡片，可以自动填入账号和密码。

登录页的“注册开发人员账号”进入 `/register`。注册成功后返回登录页，新账号由负责人添加进项目后即可接收任务。管理员登录后进入角色与权限页 `/admin/roles`，可以创建和分配角色。三种身份均可查看和修改本人资料；账号、密码和角色不能通过资料表单更改。登录成功会刷新会话 ID，退出后会话失效。原演示账号的明文密码会在成功登录时升级为加盐 PBKDF2 哈希。

自定义角色继承三种基础权限之一，不是任意勾选权限的细粒度权限矩阵。角色管理仅限管理员，表单校验 CSRF；不允许降级最后一个管理员。仍负责项目的负责人、仍属于项目的开发人员不可直接切换权限类型，需先处理项目职责；同一权限类型下可自由更换自定义角色。启动时自动创建内置角色并关联已有用户。

## 推荐演示流程

1. 使用 `manager / 123456` 登录。
2. 点击“创建项目”，填写项目名称和简介。

## 三角色基础权限（E1-06）

登录后可从侧栏访问 `/access` 查看权限矩阵。统一拦截器先从数据库确认真实身份，再校验业务路径，新增路径默认不开放；控制器和服务层保留二次校验。未登录或角色不符的请求返回登录入口，已登录用户会回到对应角色首页。

| 范围 | 管理员 | 项目负责人 | 开发人员 |
| --- | --- | --- | --- |
| 个人资料 | 本人 | 本人 | 本人 |
| 创建角色与分配角色 | 允许 | 禁止 | 禁止 |
| 项目、成员、任务管理 | 禁止 | 自己负责的项目 | 禁止 |
| 项目与团队资料查看 | 禁止 | 自己负责的项目 | 已加入的项目 |
| 任务状态更新 | 禁止 | 禁止 | 本人任务且成员正常参与 |

管理员不是绕过项目归属检查的超级项目负责人。规划功能预览仍是只读占位，不能据此认为相应业务已实现。此处是三种基础角色权限，并非可配置的细粒度权限矩阵。

负责人在工作台使用“编辑项目”，展开“成员状态与职责管理”编辑或移除成员。开发人员通过侧栏“项目与成员”查看真实项目资料和团队职责。移除成员前需要将其全部任务（包含已完成任务）转交其他正常参与的成员；暂停成员仍可只读查看已有任务，恢复后可继续更新状态。原有成员记录的空状态按正常参与处理。

## 切换到 MySQL

1. 确保 MySQL（可运行在 Docker 容器中）已启动并已创建数据库。
2. 通过环境变量设置连接地址、账号和密码，密码不要写入源代码。
3. 使用 MySQL 配置启动：

```powershell
$env:AIMANAGE_DB_URL="jdbc:mysql://localhost:3306/aimanage?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false"
$env:AIMANAGE_DB_USERNAME="root"
$env:AIMANAGE_DB_PASSWORD="你的MySQL密码"
java -jar target/aimanage-prototype-0.0.1-SNAPSHOT.jar --spring.profiles.active=mysql
```

默认连接串启用了 `createDatabaseIfNotExist=true`，账号有建库权限时会自动创建 `aimanage` 数据库；否则请先手动执行：

```sql
CREATE DATABASE aimanage CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

## 原型说明

本项目以课堂演示为目标。当前实现注册、登录、基础角色隔离及项目成员任务协作流程，不代表规划文档中的 Sprint 1 全部完成。新注册密码以加盐 PBKDF2 保存，已有明文演示密码在成功登录时升级。尚未引入 Spring Security；CSRF 防护、登录限流、完整权限管理和操作日志仍需继续完善。
